# Compras ORDEN 4.0 (borrador anterior)

> OCR, revisión, catálogo e historial se completaron después de este borrador. Consultar [compras actuales](ORDEN_4_COMPRAS_ACTUAL.md).

La lista compartida y la asociación compra/gasto existentes permanecen en el Engine. La migración ORDEN 4.0 agrega una ruta de agente reutilizable, pero todavía no incorpora OCR de tickets, catálogo normalizado, comparación de presentaciones, historial de precios ni proveedor web de supermercados.

Un ticket recibido por Telegram conserva el original únicamente cuando el usuario completa una asociación válida, respetando las cuotas actuales. La extracción de líneas y precios, cuando se implemente, deberá mostrarse como borrador con trazabilidad y revisión antes de registrarla.
