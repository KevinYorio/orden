# Asistente Hogar / ORDEN 4.0

Proyecto independiente. No editar fuera de esta carpeta ni operar el ERP u otros servicios.
Leer `docs/ORDEN_4_AUDITORIA.md`, `docs/PROGRESO.md` y la documentación aplicable antes de cambios relacionados.
El alcance ORDEN 4.0 autoriza IA local opcional, OCR y extracción documental; nunca enviar datos privados a servicios externos sin autorización explícita. Un modelo propone datos, los validadores de dominio deciden qué se persiste. No habilitar acciones arbitrarias, pagos ni compras reales.
No agregar transcripción de audio, resúmenes no solicitados ni envío automático de adjuntos. Los originales se conservan y las extracciones se confirman antes de registrar hechos financieros.
Hechos inequívocos se confirman después de persistir. Los pendientes requieren fecha y responsables.
Importes enteros; `null` no es cero. Pagos, cuotas y transferencias no deben duplicar gastos.
Un escritor/emisor activo. No activar una copia vieja ni reclamar propiedad sin una parada demostrada.
Sin credenciales reales, trabajar con simuladores y documentar la dependencia. No desplegar ni inventar costos.
Usar migraciones aditivas; nunca borrar datos reales como parte de una migración.
Pruebas pertinentes acotadas; fixtures sintéticos aislados y sin datos operativos sembrados.
